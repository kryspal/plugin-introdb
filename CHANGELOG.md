# Changelog

All notable changes to this plugin are listed here. The version in `VERSION` is the single source of the version number; a published version is never changed.

## 1.0.4

- Rebuilt with Go 1.27.2 and golang.org/x/net v0.60.0 (security fixes).
- Includes the changes since the last published catalog version (1.0.2): the plugin is never locked (availability is decided by the server), plus the documentation and source cleanup for the public repository.

## 1.0.3

- Community intro, recap and outro timings from IntroDB, with optional submission of manually marked segments; the plugin is never locked, availability is decided by the server.
- Development history before this release lives in the Kryspal Media main repository; this repository starts from this version.
